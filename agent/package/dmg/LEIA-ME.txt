Control Desk Agent

1. Arraste ControlDeskAgent.app para Aplicativos e abra-o de lá.
2. O agente instala o serviço para iniciar com seu login e mostra um PIN temporário.
3. No celular, escolha "Buscar Mac na mesma rede", selecione este Mac e informe o PIN.
4. Ative ControlDeskAgent em Ajustes do Sistema → Privacidade e Segurança → Acessibilidade para controlar janelas.
5. Clique em Concluir. O agente continua em segundo plano mesmo quando a janela fecha.

Para ver o PIN de novo: abra Control Desk Agent em Aplicativos.

Para remover (terminal):
  launchctl bootout gui/$(id -u) ~/Library/LaunchAgents/com.controldesk.agent.plist
  rm -rf /Applications/ControlDeskAgent.app
