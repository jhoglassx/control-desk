Control Desk Agent

1. Arraste ControlDeskAgent.app para Aplicativos (ou dê duplo clique no app)
2. A janela abre com PIN e IP — use no celular em Parear PC (porta 8741)
3. Clique em "Abrir Ajustes de Acessibilidade" e ative ControlDeskAgent
4. Feche a janela — o agente continua em segundo plano (sem ícone no Dock)

Para ver o PIN de novo: abra Control Desk Agent em Aplicativos.

Para remover (terminal):
  launchctl bootout gui/$(id -u) ~/Library/LaunchAgents/com.controldesk.agent.plist
  rm -rf /Applications/ControlDeskAgent.app
