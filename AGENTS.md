# Agent instructions

## Commits

- Make one commit per logical change, containing every file of that change. When writing through the GitHub API or a connector, use a multi-file commit (`push_files` or the Git Data API: one tree, one commit, one ref update), never one single-file commit per file.
- Commit with the personal GitHub identity configured for this repository, never a work or employer email.
- Do not add AI co-author trailers or "Generated with" lines to commits or pull requests.
